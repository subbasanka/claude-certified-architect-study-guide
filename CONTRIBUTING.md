# Contributing

Thanks for your interest in improving this study guide!

## What We Welcome

- Corrections to inaccurate or outdated information
- Clearer explanations of architectural patterns
- Additional scenario patterns with reasoning
- Better wrong-answer elimination examples
- Formatting and readability improvements
- Links to helpful public resources (with proper attribution)

## What We Do Not Accept

- Exam dumps or leaked exam questions
- Copied proprietary certification content
- Unverifiable claims about specific exam answers
- Content that violates Anthropic's certification policies

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b improve-domain-3-notes`)
3. Make your changes
4. Ensure your changes are factual and well-sourced
5. Submit a pull request with a clear description of what you improved and why

## Style Guidelines

- Use clear, concise language
- Prefer tables for pattern comparison
- Keep domain notes focused on exam-relevant patterns
- Attribute any external sources or inspirations

## Questions?

Open an issue if you're unsure whether a contribution would be appropriate.
