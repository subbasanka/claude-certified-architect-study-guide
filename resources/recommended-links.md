## Suggested Study Workflow

Use the resources above for broad preparation, then use this repository for pattern recognition and last-mile revision.

```text
Official docs & courses → Community guides → Scenario practice → Wrong-answer review → Cheat sheet revision
```

1. **Learn the official concepts** — Start with Anthropic Academy and the official docs.
2. **Read community explanations** — Get context from articles and threads above.
3. **Practice scenario recognition** — Use [`notes/scenario-patterns.md`](../notes/scenario-patterns.md).
4. **Review wrong-answer patterns** — Use [`practice/elimination-strategies.md`](../practice/elimination-strategies.md).
5. **Final revision** — Use the [cheat sheet](../cheat-sheet/claude_architect_cheat_sheet.pdf) on exam day.
